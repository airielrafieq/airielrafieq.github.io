IoT Smart Math Challenge

An interactive mathematics learning project that combines an ESP32 quiz system with a web application to make mathematics practice more engaging.

EventInnoMath 2025
PlatformESP32 · Firebase · Web
RoleDeveloper
01 — Details

Project Overview

The system uses an LCD to display mathematical questions and a 4×4 keypad for students to submit their answers. A buzzer provides feedback, while a web application supports player registration and leaderboard presentation.

Firebase and REST-based communication were explored to exchange information between the web application and the ESP32 system, including player information and scores.

02 — Role

My Contributions

Concept & Design

Developed the concept of an interactive IoT mathematics challenge.

Hardware Integration

Programmed ESP32, I2C LCD, 4×4 matrix keypad, and buzzer feedback.

Web Development

Built user registration, live quiz support, and real-time leaderboard pages.

Cloud & Data

Integrated Firebase real-time database and managed live score handling.

Key Learning

Microcontroller programming, web development, database integration, data handling, and real-time hardware debugging.
